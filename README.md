# UML OJ Canvas

独立的浏览器端 UML 类图画布原型，与 `uml-oj` 分开运行；画布功能会择机同步到 OJ。不使用 draw.io，也不需要外部 iframe。

## 运行

需要 Node.js 22.18 或更高版本：

```bash
npm install
npm run dev
```

打开 Vite 输出的本地地址。默认示例展示 `Classroom` 与 `Student` 的一对多关联。

## 当前能力

- 在“添加元素”菜单中选择类或接口并拖动位置；点击后可逐项添加和编辑属性、方法及方法参数，分别填写名称、可见性和类型。暂不识别的现有成员声明会以只读原文保留。
- 添加普通关联；点击连线，在面板中选择两端的类、方向、名称及各端多重性。
- 编辑面板位于画布右侧；窄屏以右侧浮层显示。使用“应用更改”提交，未应用的输入会阻止源码编辑和格式切换；关闭前会确认是否放弃，可撤销编辑。
- 与 PlantUML 和 Mermaid 的有限类图子集双向同步。源码不完整或存在不支持的内容时保留原文和最后有效画布，不会以旧模型冒充当前源码。
- 本地保存文档、画布位置和未应用面板输入；支持导出 JSON 草稿备份。数据只在当前浏览器和来源下有效，不支持多标签页并发编辑。
- 默认暗色，可切换亮色；窄屏可在画布和源码之间切换。

## 范围及限制

本原型只处理英文标识符的普通类、接口、属性、方法、普通有向或无向关联，以及两端多重性；不支持完整 UML、接口实现关系、继承、组合、复杂类型、任意图形、导入 draw.io 或草稿文件。源码有语义变化时会重新生成，注释和原排版可能变化。复杂关系重叠、自关联和大图的布局交互仍是早期原型，不承诺完整编辑器能力。重要内容请及时使用“备份草稿”。

## 验证

```bash
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

可设置 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 使用已安装的 Chromium。浏览器测试启动本地 Vite 服务，不连接外网画布。
