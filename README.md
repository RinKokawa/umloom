# UML OJ Canvas

独立的浏览器端 UML 类图画布原型，与 `uml-oj` 分开运行；画布功能会择机同步到 OJ。不使用 draw.io，也不需要外部 iframe。

## 运行

需要 Node.js 22.18 或更高版本：

```bash
npm install
npm run dev
```

打开 Vite 输出的本地地址。默认示例展示 `Classroom` 与 `Student` 的一对多关联。

## 当前能力

- 在“添加元素”菜单中选择类或接口并拖动位置；点击后可逐项添加和编辑属性、方法及方法参数，分别填写名称、可见性和类型。暂不识别的现有成员声明会以只读原文保留。
- 从类或接口左右的连接点拖到另一个元素（或其连接点）即可创建普通关联，也可以用“添加关系”按钮。选中连接点后按 Enter，再用 Tab 选择另一个元素的连接点并按 Enter，可通过键盘连线；Escape 取消。连线后可在面板修改类型、名称和多重性，并一键交换起点与终点（多重性随类移动，有向关系方向反转）；继承、实现的起点是子类或实现类，终点是父类或接口。连接点用于发起连线，最终线条的出入口会自动选择；自关联仍需在关系面板中设置。
- 拖动画布空白处平移，滚轮或双指缩放；左下角可缩放、适应内容或重置视图。聚焦画布后可用方向键平移、加减键缩放、`0` 重置。视图调整不修改源码或节点布局。
- 类旁可显示图标：按已收录的类名先匹配 Lucide，再匹配 UMLoom 自绘图标和本地收藏，未匹配使用通用图标；支持逐类更换、隐藏或整体关闭。属性面板中可主动搜索 Iconify 提供的 Tabler 图标：只有点击搜索才发送关键词，不会自动联网。已选结果保存在本地图标库（上限 100 个），可在其他类复用；移除收藏不影响已使用的类。图标只影响显示，不影响源码或模型。
- 编辑面板位于画布右侧；窄屏以右侧浮层显示。使用“应用更改”提交，未应用的输入会阻止源码编辑和格式切换；关闭前会确认是否放弃，可撤销编辑。
- 与 PlantUML 和 Mermaid 的有限类图子集双向同步。源码不完整或存在不支持的内容时保留原文和最后有效画布，不会以旧模型冒充当前源码。
- 本地保存文档、画布位置、图标设置和未应用面板输入；支持导出 JSON 草稿备份，备份包含图标选择及本地收藏。数据只在当前浏览器和来源下有效，不支持多标签页并发编辑。
- 默认暗色，可切换亮色；窄屏可在画布和源码之间切换。

## 范围及限制

本原型只处理英文标识符的普通类、接口、属性、方法、普通有向或无向关联、继承和实现关系，以及两端多重性；不支持完整 UML、组合、复杂类型、任意图形、导入 draw.io 或草稿文件。源码有语义变化时会重新生成，注释和原排版可能变化。复杂关系重叠、自关联和大图的布局交互仍是早期原型，不承诺完整编辑器能力。重要内容请及时使用“备份草稿”。

## 验证

```bash
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

可设置 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 使用已安装的 Chromium。浏览器测试启动本地 Vite 服务，不连接外网画布。
